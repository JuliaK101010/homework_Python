# 🚀 Автоматизированное тестирование (Урок 10)

Проект содержит UI-автотесты для интернет-магазина **SauceDemo** и **Slow Calculator**, реализованные с использованием паттерна **Page Object**, фреймворка **pytest** и системы отчетности **Allure**.

## 📋 Системные требования и зависимости

Перед запуском проекта на компьютере должны быть установлены:
* **Python** (версии 3.8 и выше)
* **Allure Commandline** (для генерации и просмотра отчетов)
* Браузер (Chrome / Firefox) и соответствующие веб-драйверы

### Установка необходимых Python-пакетов
Вы можете установить все требуемые библиотеки одной командой, выполнив в терминале:

pip install pytest selenium allure-pytest flake8

Структура проекта

lesson_10/pages/ — классы страниц (Page Object):
auth_page.py — страница авторизации
products_page.py — страница товаров
cart_page.py — корзина
checkout_page.py — оформление заказа
calculator_page.py — страница медленного калькулятора
lesson_10/test_shop.py — UI-тесты для интернет-магазина SauceDemo
lesson_10/test_calculator.py — UI-тест для калькулятора

Проверка кода (Линтер)
Для проверки кода на соответствие стандартам PEP 8 выполните:
flake8 lesson_10

Запуск тестов и формирование отчета
Для запуска тестов с автоматической генерацией результатов Allure выполните команду в корне проекта:
pytest --alluredir=allure-results lesson_10/

Просмотр Allure-отчетов
Чтобы открыть сгенерированный интерактивный отчет в браузере, выполните:
allure serve allure-results
